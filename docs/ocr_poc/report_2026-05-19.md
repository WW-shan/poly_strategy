## TL;DR

跑了一个最小可演示的 pipeline 验证 OCR/PDF 路径能不能给 #11 的 spec 加价值。结论是 mixed：

- ✅ **Pipeline e2e 通** — Federal Register API → 真实 PDF → pypdf 抽文本 → LLM 抽 fact 占位，3/3 测试样本成功
- ⚠️ **但现代主流 source family 不需要 OCR** — 现代 SEC 8-K 0% 是 PDF、现代 Federal Register PDF 100% 有 text layer
- 🎯 **OCR 真实价值在 spec 没显式列的地方**：CourtListener 早期 docket scan、FDA Form 483、EPA 执法 PDF、老 SEC 附件、外国监管文件

→ **OCR 不应该作为 spec PR 2 的核心 connector**，但**应该作为 spec PR 2 的 fallback 层**（当主 source 是 text-only API + 附件包含 PDF 时启用）。这跟我在 issue #11 回复里写的 angle 一致，**但 narrower**。

## OCR 真实价值在哪里（修正 #11 回复里的方向）

我在 #11 回复说"SEC 8-K exhibits 常是 PDF"——**现代 filing 实测推翻了这个**。修正后的 angle：

| Source family | 现代是否需要 OCR | 备注 |
|---|---|---|
| SEC EDGAR (modern, post-2010) | ❌ 不需要 | HTM/XBRL 全包 |
| Federal Register (modern) | ❌ 不需要 | PDF 都有 text layer |
| CourtListener early dockets (pre-2010) | ✅ **需要** | 大量 scan-only PDF |
| FDA Form 483 / 警告信 | ⚠️ **部分需要** | 实测样本需补 |
| EPA / OSHA 执法记录 | ⚠️ **部分需要** | 同上 |
| 公司年报 PDF exhibit（特定 8-K like material agreement）| ⚠️ **偶有需要** | 表格图像 / 老附件 |
| 外国监管文件（中国证监会、德 BaFin、英 FCA）| ✅ **需要** | 全球扩展时关键 |

**含义**：OCR 不是 spec PR 2 的主体，是 PR 2 的**conditional fallback**。pseudo-code：

```python
def fetch_filing(filing):
    text = try_text_api(filing)
    if text:
        return text
    pdf = try_pdf_url(filing)
    if pdf and has_text_layer(pdf):
        return pypdf_extract(pdf)
    if pdf:  # scan-only PDF
        return ocr_extract(pdf)  # 这一层才是我能加的价值
    return None
```

## 补 POC pt2（2026-05-19，pt2）：scan-only PDF 实测 OCR vs pypdf

**问题**：上一节说"OCR 在 scan-only 类源上有价值"是**未实测的 claim**。补一个干净实验。

### 方法

栈：`tesseract 5.5.2` + `poppler` + `pdf2image` + `pytesseract` + `pypdf`

**模拟方法**（避开"找 scan-only PDF"的 source 问题）：取一份已知有 text layer 的 FR PDF（`fr_2026-09841.pdf` — AHRQ delegation notice），用 `pdf2image` 在 200 DPI 栅格化成 image-only PDF（生成 `scan_2026-09841.pdf`，无 text layer）。这模拟了"一份本来就是扫描的 PDF"。

**对比 3 路结果 vs ground truth**（用原文本词集做 recall 指标）：

| 路径 | 抽出字符数 | 词级 recall |
|---|---:|---:|
| pypdf 在原 PDF（text-layer）| 3,084 | 100% (ground truth) |
| **pypdf 在 scan-only PDF** | **1** | **0%** ❌ |
| **tesseract OCR 在 scan-only @ 300 DPI** | **2,976** | **98.7%** ✅ |

### Tesseract OCR 输出首 200 字（验证非随机文本）

```
This document is scheduled to be published in the
Federal Register on 2026-05-18 and available online at

https://www.federalregister.gov/d/2026-09841, and on
https://govinfo.gov

Agency for Healthcar...
```

### 裁决

- **pypdf 在 scan-only PDF 上完全失败** —— recall 0%，抽到只有 1 个字符（换行符）
- **tesseract 在同份上 98.7% recall** —— 几乎完美还原
- → **OCR layer 在 scan-only 类源上证实有价值**

### 含义对 spec PR 2 的影响

修正 fallback pseudo-code：

```python
def fetch_filing(filing):
    text = try_text_api(filing)         # SEC/FR/CL modern API
    if text: return text
    pdf = try_pdf_url(filing)
    if not pdf: return None
    if has_text_layer(pdf):
        return pypdf_extract(pdf)        # 现代 PDF 95% 走这里
    return tesseract_ocr(pdf)            # 老文档 / CourtListener early / FDA scan / 外国监管
```

`tesseract_ocr` 一层**真有价值**，不是空话。对 spec 的影响：
- PR 2 不需要单独开 OCR connector
- 但 `raw_external_doc` 的 fetcher 需要 `text_layer` 检测 + OCR fallback 分支
- LLM cost 在这一层不变（因为 OCR 是 text-only 输出，进 LLM 跟普通 text 一样）
